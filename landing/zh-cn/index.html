为什么选择 pyobfus

本地处理

源码留在本机；Community 输出普通、跨平台的 Python 文件。

混淆后仍可调试

私有保存 mapping，可将生产 traceback 中的标识符恢复后交给开发者或 AI Agent 分析。

过程可验证

构建前扫描和预览，构建后保留语法验证、provenance 与可复现报告。

快速开始

pip install pyobfus
pyobfus --check src/
pyobfus src/ -o dist/ --save-mapping mapping.json --verify-syntax

输入/输出示例只维护一份，请查看英文 README 的 Minimal example。
