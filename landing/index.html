The problem it actually solves

Protecting source is easy. Supporting it afterwards is the hard part.

A traceback you can still read

Obfuscation normally makes production reports useless: a customer sends you a stack trace full of I0 and I7. pyobfus keeps a mapping, so --unmap turns that trace back into your original names. The mapping stays with you; the customer only ever gets the obfuscated build.

Output that runs everywhere

The result is ordinary .py files. No native runtime to install, no per-platform build, nothing extra to ship. One build works on every platform your Python already works on.

Checks before you ship, not after

--check flags what obfuscation tends to break — eval, dynamic attribute access, framework reflection — and exports SARIF for GitHub Code Scanning. --dry-run --json shows exactly what a build would do before it does it.

Start in two commands

Nothing to sign up for.

# Free, no limits on files or lines
pip install pyobfus
pyobfus src/ -o dist/ --save-mapping mapping.json

# Later, when a customer sends you an obfuscated traceback
pyobfus --unmap trace.txt --mapping mapping.json
