# Core 0.12.0 release verification — 2026-11-04

Core **0.12.0 is published**. MCP **0.3.17**, runtime **0.1.1** and VS Code
extension **0.4.3** remain unchanged. The maintainer explicitly approved the
release on November 4 after reviewing the prepared candidate.

## Source and hosted checks

- Candidate [PR #181](https://github.com/zhurong2020/pyobfus/pull/181) was merged
  as `73ff6a8ec20b4c93aa25ea1572d3b5909cf2605c`; immutable tag `v0.12.0`
  points to that exact revision.
- The final revision's [manual full CI](https://github.com/zhurong2020/pyobfus/actions/runs/41751788652)
  passed **47/47 jobs**, including all **21 OS/Python cells**, L3 delivery,
  MCP SDK compatibility, runtime boundary and benchmark checks.
- [Push CI](https://github.com/zhurong2020/pyobfus/actions/runs/41751771121),
  [CodeQL](https://github.com/zhurong2020/pyobfus/actions/runs/41751771095) and
  [Linux packaging](https://github.com/zhurong2020/pyobfus/actions/runs/41751771150)
  also passed. No ruleset was changed.
- Local `scripts/check.sh`, changelog and runtime-version checks passed.
  Each Python root ran separately with normal HOME: Core **4977 passed / 55
  skipped**, MCP **167 passed**, integration **368 passed / 10 skipped**,
  runtime **24 passed**. Benchmark smoke/key-exposure tests: **8 passed**.

  inspection, isolated installs, `pip check`, Community canary execution (`25`)
