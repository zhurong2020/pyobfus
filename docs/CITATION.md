# How to Cite

If you use **pyobfus** in academic work or want to reference it, please cite the
archived release on Zenodo. The **concept DOI** below always resolves to the
latest version:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20846053.svg)](https://doi.org/10.5281/zenodo.20846053)

## APA

> Zhu, R. (2026). *pyobfus: An AST-based Python obfuscator with reverse
> stack-trace mapping for AI-assisted development*. Zenodo.
> https://doi.org/10.5281/zenodo.20846053

## BibTeX

```bibtex
@software{zhu_pyobfus,
  author    = {Zhu, Rong},
  title     = {pyobfus: An AST-based Python obfuscator with reverse stack-trace mapping for AI-assisted development},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.20846053},
  url       = {https://doi.org/10.5281/zenodo.20846053}
}
```

## Notes

- The **concept DOI** `10.5281/zenodo.20846053` covers all versions and always
  resolves to the most recent archived release; cite it unless you need to pin a
  specific version.
- Machine-readable metadata lives in [`CITATION.cff`](https://github.com/zhurong2020/pyobfus/blob/main/CITATION.cff)
  at the repository root, which powers GitHub's "Cite this repository" widget.
- `pyobfus-mcp` is part of the same repository and is covered by the same DOI —
  no separate citation is needed.
