# 对外主张、服务承诺与协议起草原则

状态：2026-11-25 维护者确定的内部起草与复核规范；不是新增客户合同、服务保证或合规认证。
适用于后续产品发布说明、网站、用户文档、隐私政策、条款与客户通知。

## 核心原则

以事实和验证范围描述产品能力；不主动扩大未经批准的保证、服务义务或责任。
按实际控制范围说明用户测试、部署、代码与密钥管理责任，清楚披露限制。
适用的强制法律义务、不可排除的客户权利及既有承诺需要分别核对，不能用笼统免责代替。
这是一项降低过度承诺风险的规则，不代表可以任意选择有利法域或将所有责任转给用户。

## 起草与复核要求

1. **主张有证据和边界**：明确已发布／未发布、平台、版本、配置及测试范围。
   不保证不可逆、无漏洞、绝对安全、所有框架兼容、客户业务合规或特定部署适用。
   静态检查、provenance 和交付报告不能描述成全面安全认证。
2. **行为、目标和法律义务分开**：可复现的技术事实按事实披露；一般支持目标不暗示 SLA。
   不擅自新增删除／答复／通知的统一天数、可用性、赔付、客户索赔补偿或扩大责任上限。
   按适用法律处理的措辞，不能代替实际执行法定期限和必要控制措施。
3. **数据请求可受理、可核验**：保留清晰联系渠道，核验限于合理必要范围。
   删除范围、法定例外、服务商和备份分别处理；不承诺收件即删除所有副本。
   不统一声称身份核验完成后才开始计时；计时、延期与拒绝条件取决于适用法律。
4. **通知不混淆**：区分普通支持、隐私请求、向监管机构的泄露通知和向个人的通知。
   不将某一法域的一项期限概括成全球统一客户保证。
5. **责任按控制范围划分**：说明客户对其代码权利、依赖、测试、源文件／mapping／key 备份及
   应用部署的责任。第三方不可用不等于我们自动免除法定责任，也不承诺第三方履约时间。
6. **免责以可执行性为目标**：AS IS、损失类型排除和责任上限须核对适用法与 B2B/B2C 差异。
   保留不可排除的权利、救济和责任；加“法律允许范围内”本身不证明条款有效。
7. **既有承诺单独评估**：区分新客户、现有合同及此前收集的数据。通知／等待期不当然使
   不利修改可追溯生效；继续使用不能替代依法需要的同意。公开承诺已经存在时不得只改文案就
   宣称义务消失。价格、退款、设备额度、终身更新等既有交易权益不随此次原则自动改变。
8. **发布前留下证据**：记录原文、修订稿、差异、依据日期、适用范围、未知项与审核结论。
   未核实的跨境机制、删除操作或合同可执行性记为待核，不写成已完成合规。

## 调研依据与解释范围

以下官方来源于 2026-11-25 查询；来源说明监管原则，未确定本项目的适用法或条款效力。

- [FTC 隐私与安全指引](https://consumer.ftc.gov/business-guidance/privacy-security)：公开隐私承诺需要兑现。
- [欧盟企业消费者合同指南](https://europa.eu/youreurope/business/selling-in-eu/consumer-contracts-guarantees/consumer-contracts/index_en.htm)：公平、透明和不公平条款的效力；该页讨论 B2C，不据此概括全部 B2B。
- [欧盟委员会个人权利请求指引](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/dealing-requests-individuals_en)：请求响应、核验与法定条件。
- [ICO 删除权指引](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/individual-rights/individual-rights/right-to-erasure/)：删除权并非绝对、备份及核验处理；页面提示英国近期立法后该指引正复核，不据其推定全球规则。
- [EDPB 数据泄露指引](https://www.edpb.europa.eu/sme/assess-the-risks/data-breaches_en)：GDPR 下向监管机构通知与向个人通知的条件／期限不同。
- [FTC Gateway 案件材料](https://www.ftc.gov/legal-library/browse/cases-proceedings/042-3047-gateway-learning-corp-matter)：旧隐私承诺与追溯改变数据用途的风险；不泛化为一切条款更新均须 opt-in。
- [欧盟委员会跨境转移规则](https://commission.europa.eu/law/law-topic/data-protection/international-dimension-data-protection/rules-international-data-transfers_en)：跨境处理可能需要有效机制，文案限定不能替代该机制。

具体销售主体、目标市场、B2B/B2C、处理角色及历史交易决定适用范围；LLM 复核不能认证法律有效性。
