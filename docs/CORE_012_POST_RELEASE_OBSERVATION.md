## 问题分级和处理

| 情况 | 分类与下一步 |
|---|---|
| 产物行为改变、Community 被错误要求授权、私有材料泄露 | 优先工程事件：保留最小证据，暂停受影响的后续推广/渠道切换并由维护者决定处置；不等周报 |
| 已配置正确 secret 的有效 Pro 授权可复现地被拒 | 高优先支持/正确性排查；核版本、入口、脱敏状态和时间窗，避免紧密重试 |
| 缺 secret、错误 pin、fork PR 没有 secret、仍使用旧 Action 输入 | 配置迁移/支持问题；给对应说明，修复配置后复验，不归为 Core 回归 |
| 服务暂不可达或 429 | 先记录与已有监控对照；CI 按设计拒绝，持续故障再升级排查，不用失败即拒绝本身证明 bug |
| 单日下载尖峰或下降 | 核查截止日期、发版/内容/CI 活动；样本不足记 unknown，不用它驱动回滚或发版 |
| 无新增邮件 | 仅表示本次检索未发现相关回复，不推断无人使用或全部升级成功 |

回滚不是默认降到旧版本：旧版本可能缺少本次授权/安全修复。先限定受影响范围，
由维护者选择修复版本或有记录的恢复方案；不覆盖已发布 PyPI 文件、不移动不可变版本 tag。
任何发信、许可重发、服务配置或生产部署按其实际授权执行，本表不自动执行这些动作。
