# pyobfus v0.5.0 — Public Release Plan (Phase 5)

**Status**: 🟢 0.5.0 BUILT 2026-06-18, awaiting push/publish (maintainer-gated).
Patent gate cleared 2026-06-17 (初步审查合格通知书, 申请号 202610712171X, priority
2026-05-22); the six mechanisms are merged, tested (1016 pass / 1 skip), packaged,
and `dist/` artifacts pass `twine check`.

**Decisions locked 2026-06-18**: (1) disclose now; (2) drop Python 3.8 → floor
3.9; (3) all six mechanisms in 0.5.0. **Scope split**: 0.5.0 ships the mechanisms
as the `pyobfus_pro` API + `pyobfus-unscrub` CLI + standalone build passes; the
combined `pyobfus build --flag` fusion (needs Core parameterization to resolve
emitted-import mangling / dynamic emitted constants / vault-vs-string-encryption)
is **deferred to 0.5.1**.

This is the operational checklist for shipping v0.5.0. Feature-level only —
mechanism detail lands with the code in Phase 5.2.

> **Single hard rule that survives the gate clear**: `pyobfus-legal/` (patent
> dossier, contains PII) never enters git. The Pro mechanism merge is a
> deliberate one-time disclosure done in Phase 5.2 below — not incidental.

## Phase 5.1 — Decisions to lock before merging (needs maintainer)

These are the choices that change the shape of the release. Resolve them first.

- [ ] **Disclose now, or wait for 18-month publication (≈2027-11)?** Filing is
      done and priority is secured, so disclosing now is patent-safe. The only
      reason to wait would be commercial (keep the mechanisms non-public longer).
      Default assumption per 2026-06-17 instruction: **disclose now.**
- [ ] **Drop Python 3.8?** ROADMAP lists this as a v0.5 candidate (3.8 is EOL
      Oct-2024; recurring `astunparse` CI flakes — see `PYTHON38_COMPATIBILITY.md`).
      Decision affects the test matrix and `requires-python`. Recommend: drop in
      0.5.0, bump floor to `>=3.9`.
- [ ] **Single 0.5.0, or split 0.5.0 / 0.5.1?** ROADMAP currently splits P2-11
      (Runtime String Vault) into 0.5.1. All six are implementation-complete in
      `pyobfus-pro-dev`, so bundling into one 0.5.0 is feasible. Recommend: ship
      all six in 0.5.0; keep the smaller 0.5.1 parity items (P2-12/14/15/16) for later.
- [ ] **Pricing impact**: none. Single-tier $45 is unchanged (see memory
      `pricing_strategy.md`). These features are part of the existing Pro license.
