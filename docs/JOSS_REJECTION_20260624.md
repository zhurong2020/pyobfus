# Citing pyobfus (software paper status)

This page used to hold maintainer notes about a 2026 journal submission. Those
notes now live in private maintainer records; this URL is kept so older links
still resolve.

**How to cite the software:** use the Zenodo concept DOI
[`10.5281/zenodo.20846053`](https://doi.org/10.5281/zenodo.20846053), which
always resolves to the latest archived release. Full formats (APA, BibTeX,
`CITATION.cff`) are on [How to cite](CITATION.md).

**Publication status, stated plainly:** a software paper submitted to the
Journal of Open Source Software in June 2026 was not accepted (JOSS review
issue `openjournals/joss-reviews#10788`). pyobfus currently has **no
peer-reviewed journal paper**. The Zenodo DOI is a software archive, not a
peer-reviewed publication.
